How I Approach a Project

1

Understand the Need

Clarify the intended users, the problem to solve, the information involved, and the expected outcome before choosing a technical approach.

2

Outline the user interface, application logic, data, and dependencies so work can be developed and reviewed in manageable parts.

3

Build and Check

Implement the agreed scope, test important flows, record issues, and communicate clearly about what is complete and what remains planned.
